# VIGIL — Full Competition Prototype

This is a complete VIGIL student-safety prototype.

## Included
- Login
- Signup
- Unique VIGIL ID generation
- ID confirmation screen
- Home
- Vision / Mission / Motto
- Awareness hub
- Anti-Ragging: 4 pages
- Anti-Drug: 4 pages
- User-provided awareness videos
- User-provided VIGIL logo
- What Should I Do?
- Report the Incident
- Emergency guidance
- Support
- Profile
- Logout
- Responsive mobile-first UI

## Important prototype note
Authentication and reporting use browser localStorage for demo purposes. Do not use this approach for real production accounts, passwords, or sensitive reports. A secure backend/database and proper authentication are required for production.

## Run locally
1. Install Node.js.
2. In this folder run:
   npm install
3. Then:
   npm run dev

## Vercel
Import this project/repository into Vercel. The default Vite build should work:
- Build command: npm run build
- Output directory: dist

No TanStack generated route tree is required in this version.
